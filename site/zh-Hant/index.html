使用前先了解

了解支援範圍、計算方式與資料保存方式。

SkillGlance 是什麼？

SkillGlance 是一款 macOS 選單列 App，整合六種 AI 工具的本機 Skills 使用紀錄。它會分開統計明確呼叫、已確認的檔案讀取與結果未知的請求，資料保留在你的 Mac。

支援哪些 AI 工具？

Codex、Claude Desktop Code、Claude Code（CLI）、Gemini CLI、Cursor 與 Antigravity。實際可統計的內容，取決於本機有哪些紀錄，以及 App 是否支援該格式。不包含 Claude 的一般聊天紀錄。

我自己指定的 Skills 也會計入嗎？

會。不論由你指定或由 AI 選用，只要能確認呼叫或內容載入，就會計入。只在對話中提到 Skill 名稱，不算成功使用。

為什麼呼叫和讀取要分開計算？

呼叫 Skill 時，可能同時載入它的指示；直接讀取 Skill 檔案時，也可能沒有額外的呼叫紀錄。因此，兩種次數分開呈現，直接相加可能重複計算同一次使用。

Antigravity 可以統計到什麼程度？

目前只能從完整對話紀錄中辨識明確的 Skill 檔案讀取請求。由於紀錄缺少可配對的呼叫或結果 ID，無法確認讀取是否成功，因此列為「結果未知」，不計入已確認讀取或已確認有使用的對話數，也不據此推算成功次數。

所有 Cursor 版本都支援嗎？

目前只支援已驗證的內部 SQLite 紀錄格式（v3 與 read_file_v2），並分別保留成功、失敗與未知結果。遇到不支援的版本、紀錄缺漏或資料庫無法讀取時，會標示統計不完整，不會當作沒有使用。

SkillGlance 會刪除 Skills 嗎？

不會。App 只提供檢視建議，並可在 Finder 中開啟來源位置。列入移除建議前，必須有完整的 90 天觀察紀錄與足夠的使用資料。已標記為重要、系統內建或由工具管理的 Skills 都會受到保護。

哪些資料會保存在 Mac 裡？

事件摘要、來源位置、讀取進度、專案掃描範圍與重要標記。App 不保存完整對話或工具輸出，也不會上傳你的紀錄。

支援哪些 Mac 與介面語言？

目前版本適用於 Apple Silicon Mac，系統需求設定為 macOS 14 或以上版本；實機測試僅涵蓋執行 macOS 27.0.1 的開發用 Mac。介面提供英文、簡體中文與繁體中文，依 macOS 的語言偏好顯示。

如何安裝 App？

開啟 DMG，將 SkillGlance 拖入 Applications（應用程式）資料夾，再從該資料夾開啟 App。0.3.1 為 ad-hoc 簽署的測試版，尚未完成 Apple 公證（notarization）。
