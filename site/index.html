Good to know

What the App can see, what it counts, and what it leaves to you.

What is SkillGlance?

SkillGlance is a macOS menu bar app that summarizes local AI Skills usage across six tools. It separates explicit calls, confirmed file reads and requests with unknown results, while keeping records on your Mac.

Which AI tools are supported?

Codex, Claude Desktop Code, Claude Code (CLI family), Gemini CLI, Cursor and Antigravity. Coverage depends on locally readable records and supported formats. Claude general chat is outside this scope.

Does it count Skills I select myself?

Yes. Both user-selected and AI-selected Skills count when a call or content load can be confirmed. Mentioning a Skill name alone does not count as successful use.

Why are calls and reads separate?

They describe different evidence. A Skill call can also load instructions, while a direct content load may have no separate call. Adding the two can double-count the same activity.

What can Antigravity evidence confirm?

Only explicit Skill-file read requests in full transcripts. These records do not provide paired call or result IDs, so outcomes stay unknown. They do not increase confirmed-read or confirmed-active-chat counts; the App does not infer full success statistics.

Are all Cursor versions supported?

Cursor support covers a verified internal SQLite format (v3 records and read_file_v2). Success, error and unknown results stay separate. Unrecognized versions, missing records or inaccessible databases mean incomplete evidence, not zero usage.

Will SkillGlance delete my Skills?

No. The current version provides suggestions and Finder navigation. A candidate needs a full 90-day observation period and complete evidence. Important and managed Skills remain protected.

What stays on my Mac?

Event summaries, source locations, scan progress, project folders and important flags. The App does not store complete conversations or tool output, and does not upload your records.

Which Macs and languages does it support?

The current build targets Apple Silicon and declares macOS 14 as the minimum. It has only been tested on the development Mac running macOS 27.0.1. The App includes English, Simplified Chinese and Traditional Chinese, selected through macOS language preferences.

How do I install the App?

Open the DMG, drag SkillGlance into Applications, then open it from Applications. Version 0.3.1 is an ad-hoc signed test release and has not completed Apple notarization.
