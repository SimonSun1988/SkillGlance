使用前先了解

了解支持范围、计算方式与数据存储方式。

SkillGlance 是什么？

SkillGlance 是一款 macOS 菜单栏 App，整合六种 AI 工具的本地 Skills 使用记录。它会分别统计明确调用、已确认的文件读取与结果未知的请求，数据保留在你的 Mac。

支持哪些 AI 工具？

Codex、Claude Desktop Code、Claude Code（CLI）、Gemini CLI、Cursor 与 Antigravity。实际可统计的内容，取决于本地有哪些记录，以及 App 是否支持该格式。不包含 Claude 的普通聊天记录。

我自己指定的 Skills 也会计入吗？

会。无论由你指定还是由 AI 选用，只要能确认调用或内容加载，就会计入。只在对话中提到 Skill 名称，不算成功使用。

为什么调用和读取要分开统计？

调用 Skill 时，可能同时加载它的指令；直接读取 Skill 文件时，也可能没有额外的调用记录。因此，两种次数分别呈现，直接相加可能重复统计同一次使用。

Antigravity 可以统计到什么程度？

目前只能从完整对话记录中识别明确的 Skill 文件读取请求。由于记录缺少可配对的调用或结果 ID，无法确认读取是否成功，因此列为“结果未知”，不计入已确认读取或已确认有使用的对话数，也不据此推算成功次数。

所有 Cursor 版本都支持吗？

目前只支持已验证的内部 SQLite 记录格式（v3 与 read_file_v2），并分别保留成功、失败与未知结果。遇到不支持的版本、记录缺失或数据库无法读取时，会标明统计不完整，不会当作没有使用。

SkillGlance 会删除 Skills 吗？

不会。App 只提供检查建议，并可在 Finder 中打开来源位置。列入移除建议前，必须有完整的 90 天观察记录与足够的使用数据。已标记为重要、系统内置或由工具管理的 Skills 都会受到保护。

哪些数据会保存在 Mac 里？

事件摘要、来源位置、读取进度、项目扫描范围与重要标记。App 不保存完整对话或工具输出，也不会上传你的记录。

支持哪些 Mac 与界面语言？

当前版本适用于 Apple Silicon Mac，系统要求设为 macOS 14 或更高版本；实机测试仅覆盖运行 macOS 27.0.1 的开发用 Mac。界面提供英文、简体中文与繁体中文，按 macOS 的语言偏好显示。

如何安装 App？

打开 DMG，将 SkillGlance 拖入 Applications（应用程序）文件夹，再从该文件夹打开 App。0.2.1 为 ad-hoc 签名的测试版，尚未完成 Apple 公证（notarization）。
